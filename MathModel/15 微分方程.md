## 15.1 定义

微分方程是描述**未知函数及其导数之间关系**的方程。

## 15.2 求解

**导入**：
```python
from scipy.integrate import solve_ivp
```

**函数原型**：

```python
solve_ivp(
    fun,
    t_span,
    y0,
    method='RK45',
    t_eval=None,
    dense_output=False,
    events=None,
    vectorized=False,
    args=None,
    **options
)
```

| 参数             | 类型            | 含义                                   |
| -------------- | ------------- | ------------------------------------ |
| `fun`          | callable函数    | 微分方程右端函数，表示 ($\frac{dy}{dt}=f(t,y)$) |
| `t_span`       | tuple         | 积分区间 `(起点,终点)`                       |
| `y0`           | array_like    | 初始条件 ($x(0)=1,y(0)=2$)，则填入`[1,2]`    |
| `method`       | str           | 数值积分算法                               |
| `t_eval`       | array_like    | 指定返回结果的时间点                           |
| `dense_output` | bool          | 是否生成连续解函数                            |
| `events`       | callable/list | 定义事件函数，用于检测特殊情况                      |
| `vectorized`   | bool          | 是否允许向量化计算，提高部分算法效率                   |
| `args`         | tuple         | 传递给 `fun` 的额外参数                      |
| `rtol`         | float         | 相对误差容限                               |
| `atol`         | float         | 绝对误差容限                               |
| `first_step`   | float         | 第一步积分步长                              |
| `max_step`     | float         | 最大积分步长                               |
| `min_step`     | float         | 最小允许步长（部分算法支持）                       |

非刚性问题指变化较慢的函数：

|类型|常用算法（`method`）|特点|适用情况|
|---|---|---|---|
|**非刚性问题**|`RK45`|自适应步长，精度和效率平衡，默认方法|大多数普通微分方程，如人口模型、运动模型、一般动力系统|
|**非刚性问题**|`DOP853`|高阶Runge-Kutta，精度更高|长时间积分、高精度模拟、科研计算|
|**刚性问题**|`BDF`|隐式多步法，稳定性强|化学反应、控制系统、生物动力学等刚性ODE|
|**刚性问题**|`Radau`|隐式Runge-Kutta，稳定且高精度|强刚性问题，对精度要求高的工程模型|
|**未知是否刚性**|`LSODA`|自动判断并切换算法|复杂系统、不确定模型性质时|


**返回值**：

| 返回属性       | 类型                | 含义      | 说明                                           |
| ---------- | ----------------- | ------- | -------------------------------------------- |
| `t`        | `ndarray`         | 时间节点    | 返回的时间序列，对应 `t_eval` 或求解器自动选择的节点              |
| `y`        | `ndarray`         | 数值解     | 每一行对应一个状态变量，每一列对应一个时间点                       |
| `sol`      | `callable / None` | 连续解函数   | `dense_output=True` 时生成，可通过 `sol(t)` 查询任意时刻解 |
| `success`  | `bool`            | 是否求解成功  | `True` 表示成功，`False` 表示失败                     |
| `message`  | `str`             | 求解结束信息  | 描述成功原因或失败原因                                  |
| `status`   | `int`             | 求解状态码   | `0`：正常结束；`1`：事件终止；`-1`：失败                    |
| `t_events` | `list / None`     | 事件发生时间  | 使用 `events` 参数时返回各事件发生的时间                    |
| `y_events` | `list / None`     | 事件发生时状态 | 对应事件发生时的状态变量值                                |
| `nfev`     | `int`             | 函数调用次数  | 微分方程右端函数 `fun` 被调用的次数                        |
| `njev`     | `int`             | 雅可比计算次数 | 主要用于隐式方法（BDF、Radau）                          |
| `nlu`      | `int`             | LU分解次数  | 主要用于隐式方法（BDF、Radau）                          |
**`y` 的结构**：

|情况|`y`形状|含义|
|---|---|---|
|单变量 (y)|`(1, n)`|第0行是 (y(t))|
|两变量 (x,y)|`(2, n)`|第0行是 (x(t))，第1行是 (y(t))|
|多变量|`(m, n)`|m个状态变量，n个时间点|
