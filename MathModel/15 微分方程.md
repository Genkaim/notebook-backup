## 15.1 定义

微分方程是描述**未知函数及其导数之间关系**的方程。

## 15.2 常用模型

### 15.2.1 人口增长模型

$Malthus$ 模型：假设人口增长率 $r$ 为常数，有

$$
\frac{dP}{dt}=rP,\quad P(0)=P_0 \;\Longrightarrow\; P(t)=P_0 e^{rt}
$$

适用于短期、资源无限的情形。

$Logistic$ 模型：考虑环境承载力 $P_m$，增长率随人口增加而下降：

$$
\frac{dP}{dt}=r\left(1-\frac{P}{P_m}\right)P,\quad P(0)=P_0
$$

解析解为 $P(t)=\frac{P_m}{1+\left(\frac{P_m}{P_0}-1\right)e^{-rt}}$，$t\to\infty$ 时 $P\to P_m$。

> 两模型核心差异：$Malthus$ 是指数增长、无上限；$Logistic$ 是 S 形曲线、趋于饱和。

### 15.2.2 $Volterra$ 捕食者模型

也称 $Lotka$-$Volterra$ 模型，描述一个地区中食饵（如兔子）和捕食者（如狐狸）两个种群的数量变化关系。

设 $x(t)$ 为食饵数量，$y(t)$ 为捕食者数量，基本假设：
1. **无捕食者时**，食饵以自然增长率 $a$ 指数增长：$dx/dt = a x$
2. **捕食作用**以正比于相遇概率（即 $x y$）的速率减少食饵
3. **无食饵时**，捕食者以死亡率 $d$ 指数衰减：$dy/dt = -d y$
4. **捕食者增长**依赖于捕食获得的能量，也正比于 $x y$

得到基本的方程组：
$$
\begin{cases}
\displaystyle \frac{dx}{dt} = a x - b x y \\[8pt]
\displaystyle \frac{dy}{dt} = c x y - d y
\end{cases}
$$

当$x,y$取得驻点时，称为**平衡点**。此时种群数量不变
$$
\begin{aligned}
ax−bxy=0 \Rightarrow x=0 或y=\frac{a}{b} \\ 
cxy−dy=0 \Rightarrow y=0 或 x=\frac{d}{c}​

\end{aligned}
$$
故又两个平衡点：$(0,0)(全部灭绝)(\frac{d}{c},\frac{a}{b})(动态平衡)$。

但是实际情况，会有其他条件影响，例如疾病，种内斗争，外部捕捞等。
考虑**外部影响**：捕捞分为两种，恒定捕捞$\frac{dx}{dt}$减去常数，比例捕捞减去$qx$。(不一定是捕捞，可以是所有其他的额外死亡/繁殖)
考虑**密度制约**：当食饵数量很多时，自增长率趋近于0。捕食者数量很多时，自减少量增加，这称为$Logistic$增长。
考虑**内部竞争**：$\sigma$为系数，内部**竞争概率**为$x^2或y^2$，故减去$\sigma x^2或\sigma y^2$：
$$
\begin{cases}
\displaystyle \frac{dx}{dt} = a x (1-\frac{x}{P_m})-bxy-qx-h \\[8pt]
\displaystyle \frac{dy}{dt} = c x y - d y(1+\frac{y}{Q_m})
\end{cases}
$$

### 15.2.3传染病模型

%%大狗叫返厂了%%

**$SI$模型**：假设$S$是易感染者。$I$是患者。假设总人数$N$不变，$t$时刻健康人和患者比例分别为$s(t),i(t)$($s(t)+i(t)=1$)，每和患者每天可以传染给$\lambda$个人（传染强度）。
一定时间增加的患者人数：
$$
N\cdot i(t+\Delta t)-N\cdot i(t) = \lambda N i(t) s(t) \Rightarrow \frac{di}{dt}=\lambda i(t)(1-i(t))
$$


**$SIS$模型**：在原先基础上，有日治愈率$\mu$，
$$
\frac{di}{dt}=\lambda i(t)(1-i(t))-\mu i (t)
$$
展开得
$$
\frac{di}{dt}=\lambda i-\lambda i ^2-\mu i=(\lambda - \mu)i-\lambda i^2
$$
也就是$Logistic$方程变形。
当$\frac{di}{dt}=0$时，$i=0$或$i=1-\frac{\mu}{\lambda}$。故$\lambda \le \mu$疾病最终消失，$\lambda > \mu$疾病长期存在。


**$SIR$模型**：某些疾病康复后会产生抗体，故新增治愈后不会感染的群体，称为移除者，称作$R$，移除者比例为$r(t)$，有$s(t)+i(t)+r(t)=1$

$$
\begin{cases}
\dfrac{ds}{dt}=-\lambda si \\[6pt]
\dfrac{di}{dt}=\lambda si-\mu i \\[6pt]
\dfrac{dr}{dt}=\mu i
\end{cases}

$$
**基本再生数**：$R_0=\frac{\lambda}{\mu}$，表示一个感染者在完全易感人群中平均产生的新感染人数。$\lambda \le \mu$疾病最终消失，$\lambda > \mu$感染人数增加，会出现疫情高峰。

**$SIRS$模型**：考虑康复人群重复感染的情况，假设康复者每天以比例 $\gamma$ 丧失免疫：
$$
\begin{cases}
\dfrac{ds}{dt}=-\lambda si+\gamma r \\[6pt]
\dfrac{di}{dt}=\lambda si-\mu i \\[6pt]
\dfrac{dr}{dt}=\mu i -\gamma r
\end{cases}

$$

> 实际建模中可以引入新的群体，隔离者，死亡者等等。处理好变化关系即可。
## 15.3 求解

**导入**：
```python
from scipy.integrate import solve_ivp
```

**函数原型**：

```python
solve_ivp(
    fun,
    t_span,
    y0,
    method='RK45',
    t_eval=None,
    events=None,
    max_step=np.inf,
    rtol=1e-3,
    atol=1e-6,
)
```

| 参数         | 类型            | 含义                                   |
| ---------- | ------------- | ------------------------------------ |
| `fun`      | callable函数    | 微分方程右端函数，表示 ($\frac{dy}{dt}=f(t,y)$) |
| `t_span`   | tuple         | 积分区间 `(起点,终点)`                       |
| `y0`       | array_like    | 初始条件 ($x(0)=1,y(0)=2$)，则填入`[1,2]`    |
| `method`   | str           | 数值积分算法                               |
| `t_eval`   | array_like    | 指定返回结果的时间点                           |
| `events`   | callable/list | 定义事件函数，用于检测特殊情况                      |
| `max_step` | float         | 最大积分步长                               |
| `rtol`     | float         | 相对误差容限                               |
| `atol`     | float         | 绝对误差容限                               |

非刚性问题指变化较慢的函数：

|类型|常用算法（`method`）|特点|适用情况|
|---|---|---|---|
|**非刚性问题**|`RK45`|自适应步长，精度和效率平衡，默认方法|大多数普通微分方程，如人口模型、运动模型、一般动力系统|
|**非刚性问题**|`DOP853`|高阶Runge-Kutta，精度更高|长时间积分、高精度模拟、科研计算|
|**刚性问题**|`BDF`|隐式多步法，稳定性强|化学反应、控制系统、生物动力学等刚性ODE|
|**刚性问题**|`Radau`|隐式Runge-Kutta，稳定且高精度|强刚性问题，对精度要求高的工程模型|
|**未知是否刚性**|`LSODA`|自动判断并切换算法|复杂系统、不确定模型性质时|


**返回值**：

| 返回属性       | 类型                | 含义      | 说明                                           |
| ---------- | ----------------- | ------- | -------------------------------------------- |
| `t`        | `ndarray`         | 时间节点    | 返回的时间序列，对应 `t_eval` 或求解器自动选择的节点              |
| `y`        | `ndarray`         | 数值解     | 每一行对应一个状态变量，每一列对应一个时间点                       |
| `sol`      | `callable / None` | 连续解函数   | `dense_output=True` 时生成，可通过 `sol(t)` 查询任意时刻解 |
| `success`  | `bool`            | 是否求解成功  | `True` 表示成功，`False` 表示失败                     |
| `message`  | `str`             | 求解结束信息  | 描述成功原因或失败原因                                  |
| `status`   | `int`             | 求解状态码   | `0`：正常结束；`1`：事件终止；`-1`：失败                    |
| `t_events` | `list / None`     | 事件发生时间  | 使用 `events` 参数时返回各事件发生的时间                    |
| `y_events` | `list / None`     | 事件发生时状态 | 对应事件发生时的状态变量值                                |
| `nfev`     | `int`             | 函数调用次数  | 微分方程右端函数 `fun` 被调用的次数                        |
| `njev`     | `int`             | 雅可比计算次数 | 主要用于隐式方法（BDF、Radau）                          |
| `nlu`      | `int`             | LU分解次数  | 主要用于隐式方法（BDF、Radau）                          |
**`y` 的结构**：

|情况|`y`形状|含义|
|---|---|---|
|单变量 (y)|`(1, n)`|第0行是 (y(t))|
|两变量 (x,y)|`(2, n)`|第0行是 (x(t))，第1行是 (y(t))|
|多变量|`(m, n)`|m个状态变量，n个时间点|
