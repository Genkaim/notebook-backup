
## 17.1 定义 

聚类根据样本之间的相似性，将数据对象划分为若干个类别（簇），使得同一簇内的对象具有较高相似性，而不同簇之间的对象具有较大差异。

### 17.1.1 距离

**样本距离**：
设两个样本：
$$
\begin{array}{c}{x_{i}=(x_{i1},x_{i2},\cdots, x_{im})}\\
{x_{j}=(x_{j1},x_{j2},\cdots, x_{jm})}\end{array}
$$
1. 欧式距离，最常用的距离，表示两个样本点之间的直线距离：
$$
d(x_{i},x_{j})=\sqrt{\sum_{k=1}^{m}(x_{ik}-x_{jk})^{2}}
$$
2. 曼哈顿距离，表示各个维度差值的绝对值之和
$$
\begin{array}{rl}&{d(x_{i},x_{j})=\sum_{k=1}^{m}|x_{ik}-x_{jk}|}\end{array}
$$
3. 闵可夫斯基距离
$$
i(x_{i},x_{j})=\left(\sum_{k=1}^{m}|x_{ik}-x_{jk}|^{p}\right)^{\frac{1}{p}}
$$
4. 切比雪夫距离
$$
d(x_{i},x_{j})=\operatorname*{max}_{k}|x_{ik}-x_{jk}|
$$

**类的距离**：
1. 最短距离，定义两个簇中距离最近的两个样本之间的距离。
$$
D(C_{i},C_{j})=\operatorname*{min}_{x\in C_{i},y\in C_{j}}d(x,y)
$$
2. 最长距离，定义两个簇中距离最远的两个样本之间的距离。
$$
D(C_{i},C_{j})=\operatorname*{max}_{x\in C_{i},y\in C_{j}}d(x,y)
$$
3. 组间平均连接，用**两个类中**所有样本对之间距离的平均值作为两个类之间的距离。
4. 组内平均连接，计算同一类中**所有样本**之间距离和**两个类中**所有样本对之间距离的平均值。
5. 重心法，使用两个类别**中心点（质心）之间的距离**作为类间距离。

## 17.2 常见模型

### 17.2.1 最短距离系统聚类法

1. 把每一个样本看成一个类，记录不同类之间距离，获得邻接矩阵。
2. 把距离最小的两个类合并。
3. 计算新类到其他类的距离，这里可以使用上面提到的不同距离算法。
$\text{e.g.}$若有样本$x_1,x_2,x_3,x_4$，初始类$G_1,G_2,G_3,G_4$，若把$x_2,x_3$合并，记作$G_5$，
那么有：
$$
\begin{aligned}
D(G_5, G_4) = \min \{ d(x_4, x_2), d(x_4, x_3)\} \\[8pt]
D(G_5, G_1) = \min \{ d(x_1, x_2), d(x_1, x_3)\} 
\end{aligned}
$$

4. 继续此过程，直到完全合并。

完成后，会得到一个二叉树，称为聚类树$dendrogram$。选择不同的截断高度可以都得到类别。

### 17.2.2 $Kmeans$聚类算法

$K-means$是一种基于划分的聚类算法，通过不断调整类别中心，使同一类别内的样本距离尽可能小，不同类别之间的样本差异尽可能大。
首先指明类别数量，随机选择 $k$个样本作为初始中心：
1. 计算每一个点到不同中心的欧氏距离。
2. 把点划分到距离最近的中心对应的类。
3. 重新计算聚类中心（重心公式）。
$$
\mu_{j}=\frac{1}{|C_{j}|}\sum_{x_{i}\in C_{j}}x_{i}
$$
4. 继续此过程，直到聚类中心或样本类别不再发生变化，或达到指定迭代上限。

### 17.2.3 $DBSCAN$算法
$Density-Based Spatial Clustering of Applications with Noise$是一种基于**密度**的聚类算法，通过分析样本点附近的密度分布，将高密度区域划分为不同类别，并能够识别噪声点。
DBSCAN主要有两个参数：
- 邻域半径$\varepsilon$：表示样本点附近的搜索范围。
- 最小样本数$MinPts$：表示一个点邻域内成为高密度区域所需的最少样本数量。

根据邻域内样本数量，将样本分为三类：
- 核心点：
$$
|N_{\varepsilon}(x_{i})|\geq MinPts
$$
- 边界点：
$$
|N_{\varepsilon}(x_{i})|<MinPts
$$
且该点位于某个核心点的邻域内。
- 噪声点
$$
|N_{\varepsilon}(x_{i})|<MinPts
$$
且该点不属于任何核心点的邻域。

1. 初始化所有样本为未访问状态。
2. 随机选择一个未访问样本 $(x_i)$，计算其 $(\varepsilon)-$邻域：
$$
N_\varepsilon(x_i)
=
\{x_j\in X|d(x_i,x_j)\leq\varepsilon\}
$$
3. 判断邻域内样本数量：
$$
|N_\varepsilon(x_i)|\geq MinPts
$$
若满足条件，则创建新的类别 $(C_k)$，并将 $(x_i)$ 加入该类别；否则将 $(x_i)$ 标记为噪声点。
4. 对类别进行扩展。
若样本 $(x_j)$ 为核心点：
$$
|N_\varepsilon(x_j)|\geq MinPts
$$
则将其邻域内样本加入当前类别：
$$
C_k=C_k\cup N_\varepsilon(x_j)
$$
并继续检查新加入样本中的核心点。

5. 重复上述过程，直到所有样本均被访问。
最终得到：

$$
X=C_1\cup C_2\cup\cdots\cup C_k\cup N
$$
其中：

- $(C_1,C_2,\cdots,C_k)$：得到的聚类类别；
- $(N)$：噪声点集合。

## 17.3 求解

### 17.3.1 $Kmeans$
**导入**：

```python
from sklearn.cluster import KMeans
```

**函数原型**：


```python
sklearn.cluster.KMeans(
    n_clusters=8,
    *,
    init='k-means++',
    n_init='auto',
    max_iter=300,
    tol=1e-4,
    random_state=None,
    algorithm='lloyd'
)
```

| 参数             | 含义       | 说明             |
| -------------- | -------- | -------------- |
| `n_clusters`   | 类别数量 (k) | 必须指定，表示最终划分的簇数 |
| `init`         | 初始化方式    | 选择初始聚类中心的方法    |
| `n_init`       | 初始化次数    | 运行多次，选择效果最好的结果 |
| `max_iter`     | 最大迭代次数   | 单次运行最多迭代次数     |
| `tol`          | 收敛阈值     | 中心变化小于该值停止     |
| `random_state` | 随机种子     | 保证结果可复现        |
**返回值**：
返回一个模型对象，使用`model.fit(X)`，传递样本：
行：样本
列：特征

| 属性                 | 含义         |
| ------------------ | ---------- |
| `labels_`          | 每个样本所属类别   |
| `cluster_centers_` | 聚类中心       |
| `inertia_`         | 类内平方和（SSE） |
| `n_iter_`          | 实际迭代次数     |
### 17.3.2 $DBSCAN$

**导入**：

```python
from sklearn.cluster import DBSCAN
```

**函数原型**：

```python
sklearn.cluster.DBSCAN(
    eps=0.5,
    *,
    min_samples=5,
    metric='euclidean',
    algorithm='auto',
    leaf_size=30,
    p=None,
    n_jobs=None
)
```

| 参数            | 含义             | 说明                         |
| ------------- | -------------- | -------------------------- |
| `eps`         | 邻域半径           | 判断样本是否在邻域内的距离阈值            |
| `min_samples` | 最小样本数 (MinPts) | 判断核心点所需的最少邻域样本数量           |
| `metric`      | 距离计算方式         | 默认使用欧氏距离                   |
| `algorithm`   | 搜索算法           | 用于计算邻域点的方法                 |
| `leaf_size`   | 树结构大小          | 影响邻域搜索速度                   |
| `p`           | 闵可夫斯基距离参数      | 当 `metric='minkowski'` 时使用 |
| `n_jobs`      | 并行数量           | 控制计算使用的线程数                 |

**返回值**：
返回一个模型对象，使用`model.fit(X)`，传递样本：
行：样本
列：特征

|属性|含义|
|---|---|
|`labels_`|每个样本所属类别|
|`core_sample_indices_`|核心样本的索引|
|`components_`|核心样本坐标|
|`n_features_in_`|输入数据特征数量|

### 17.3.3 层次聚类（最短距离法）：

**导入**：

```python
from sklearn.cluster import AgglomerativeClustering
```

**函数原型**：

```python
sklearn.cluster.AgglomerativeClustering(
    n_clusters=2,
    *,
    metric='euclidean',
    memory=None,
    connectivity=None,
    compute_full_tree='auto',
    linkage='ward'
)
```

|参数|含义|说明|
|---|---|---|
|`n_clusters`|类别数量 (k)|最终划分的簇数量|
|`metric`|距离计算方式|默认使用欧氏距离|
|`linkage`|类间距离计算方法|决定类别合并规则|
|`connectivity`|连通矩阵|限制样本合并关系|
|`compute_full_tree`|是否计算完整树|控制层次树生成方式|

其中 `linkage`：

|参数|类间距离|
|---|---|
|`'single'`|最短距离法|
|`'complete'`|最长距离法|
|`'average'`|平均距离法|
|`'ward'`|Ward方法|

**返回值**：

返回一个模型对象，使用`model.fit(X)`，传递样本：
行：样本
列：特征

|属性|含义|
|---|---|
|`labels_`|每个样本所属类别|
|`n_clusters_`|聚类数量|
|`n_leaves_`|层次树叶节点数量|
